# 墨印 · MoInk

> **把喜欢的瞬间，放在身边。**
> 基于 ESP32-C3 与华为拆机四色电子墨水屏（768×552 黑/白/黄/红）的电子照片 / 电子拍立得 / 挂件。

墨印 · MoInk 是一台可以随身携带的「电子拍立得」：手机或电脑连接设备热点（或把设备连入你家 WiFi，同一局域网直达）后，在网页里完成**选图 → 裁剪 → 风格化 → 文字排版**，一键推送到 768×552 的华为拆机四色墨水屏（黑/白/黄/红）上。断电后画面**永久保持**，功耗极低，适合做成桌面相框、冰箱贴或随身挂件。

- **不用 App**：设备自带 WiFi 热点与 captive portal，手机连上即自动弹出创作页面；也可连入路由器用局域网 IP 访问
- **不用服务器**：所有图像合成在浏览器本地完成，设备只负责「接收 → 刷屏 → 睡觉」
- **长续航**：传图完成即深度睡眠，GPIO5 按键唤醒，静态几乎零功耗；需要「每天自己动一次」时（换日历 / 换图）到点醒来干完活立刻回睡，全程不开热点

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🖼️ 四色电子照片 | 黑/白/黄/红四色墨水屏（华为拆机 768×552 屏），支持拍立得白边、文字叠加 |
| ✂️ 浏览器内裁剪 | 内嵌 Cropper.js：捏合缩放、自由旋转、90° 贴合、EXIF 方向自动摆正 |
| 🎨 eink-warm 暖调算法 | 专为四色屏设计的色彩映射 + 8 种误差扩散抖动算法，肤色自然不偏红 |
| ✏️ 所见即所得文字编辑 | 多文字对象、拖动/缩放/旋转/描边/底色，画布实时渲染，四色文字直出 |
| 🗂 首页三个内容 tab | **拍立得 / 待办 / 轮播** 并排在首页（管的都是「屏幕上放什么」），⚙ 设置页只管设备怎么运行；手机单列、桌面双栏预览 |
| ✅ 待办清单上屏 | 一句话一条、行首打勾即完成，可删可排序，两套版式（A 横线条目表 / B 红色时间轴）+ 中英牌头；**清单存在设备里**（换手机读回同一份，升级不丢），默认「勾选即上屏」，不参与轮播 |
| 🔁 一个入口搞定升级 | 固件与控制页走同一个「上传并升级」入口，上传后按内容自动识别类型：`.bin` = 固件升级（顺带更新控制页、重置 6 项显示/休眠参数，**保留热点名/密码、局域网配置、轮播画面与轮播/日历设置**、自动重启），`.html` = 只热更控制页（CRC32 校验失败自动回退内嵌页） |
| 📅 日历自动改日期 | 每天在你定的时刻（默认 00:01，任意时分）自己醒来，把**竖版日历**（黑/白/黄/红四色，**四套样式按情绪板一比一复刻、页面可选**：暖纸 = 圆角黄块 + 无框月格 + 今日黑圆 + 节假日红点；红格 = 超大红日期 + 大圆角外框月格 + 今日圆角红底；翻页牌 = 黑瓷砖大日期 + 竖列月格 + 芥末色带；打卡点阵 = 每行 5 个日期圆点 + 今日实心红点；带框处一律大 R 角；**中文 / English 可切**，法定节假日自动标记）上屏后回深睡 —— 不启热点、不联网；日期由页面同步给设备，掉电后自动补回 |
| 📸 相册轮播 | 最多 8 张画面存进设备内部；设了「换图间隔」后到点**自动换下一张直接上屏**（不启热点、不耗连网时间），顺序 / 随机两种模式，完全离线 |
| ⏱ 唤醒节奏自定义 | 「开热点等人」「轮播换图」「日历改日期」三个节奏各自独立填分钟数（0~1440），设备按最近到期的一个武装定时器；空闲休眠档位选「不休眠」也不会把节奏卡死 |
| ⚙️ 设备管理 | 热点名称/密码修改、局域网联网（连入路由器）、休眠与自动唤醒、日历设置、残影清理、恢复出厂、电池电压检测 |
| 🔋 低功耗 | 传图后自动深度睡眠（Deep Sleep），按键唤醒，适配电池供电挂件形态 |
| 🖥️ 多批次屏适配 | A0 / A1 两种拆机屏批次驱动可切换；A1 提供两档写入模式，默认「768×552 顺序直写」（1:1 覆盖可见区，零重采样、无白边） |

## 🛠️ 技术亮点

- **画面合成 100% 在浏览器端**：固件只做「热点 / 接收 / 刷图 / 休眠 / 唤醒 / 轮播 / 日历 / 升级」，保持极小体积（Flash 占用约 84%），控制页通过热更通道独立迭代
- **eink-warm 图像算法（逐行冻结）**：饱和度幂律映射 + 线性光抖动，解决四色屏「肤色发红」「画面发白」两大通病；有跨语言（Python/JS）逐像素一致性门禁 `check_algo.py`（12/12 MATCH）
- **严谨的帧协议**：16 字节帧头（魔数 / 版本 / 面板 / 尺寸 / CRC16-CCITT-FALSE）+ 2bpp 载荷（768×552 → 105,984B；A1 原生 800×600 → 120,000B），设备端逐字节校验并做几何自洽检查，坏帧直接拒绝
- **三重自愈**：控制页 CRC32 校验失败自动回退内嵌副本；OTA 双分区 + 防降级；固件升级只重置 6 项显示 / 休眠参数，**保留热点名/密码、局域网配置、轮播画面与轮播/日历设置**，不会升完就失联、不丢照片
- **多节奏定时**：「开热点等人」「轮播换图」「日历改日期」三个节奏各自倒计时，入睡时取**最近到期的一个**武装 RTC 定时器（最短 30 s 防抖）；到期者干活，其余不打扰 —— 页面只转述设备给的倒计时，不自行推算
- **并发安全**：刷屏 / 残影清理共用帧缓冲互斥锁；HTTP 上传全链喂电源看门狗，避免「传图中途深睡」

## 🚀 快速开始

详细步骤请看 **[新手入门教程](docs/入门教程.md)**，这里只列关键三步：

```bash
# 1. 编译固件（需要 Python + PlatformIO）
python -m platformio run -e moink

# 2. USB 刷机（或直接用 flash_kit/ 一键刷机包）
python tools/flash_moink.py

# 3. 手机连接设备热点 MoInk-XXXX，浏览器自动弹出创作页
```

也可以免编译直接使用 `flash_kit/` 目录里的一键刷机包（含预编译固件；没装 Python 会引导自动安装），或到 [GitHub Releases](https://github.com/mccding/huaweimoink/releases) 下载刷机包。

## 📖 使用方法

1. **连接**：设备上电后创建热点 `MoInk-XXXX`（XXXX 为 MAC 后 2 字节），手机连接后自动弹出创作页（或浏览器访问 `http://192.168.4.1`）；也可在设置里让设备连入路由器，之后同一局域网用其 IP 直接访问
2. **拍立得**（首页 tab ①）：选图 → 裁剪调整 → 可选风格/留白/文字 → 「上传并刷新屏幕」
3. **待办清单**（首页 tab ②）：写一句 → 「添加」→ 完成就打勾；选版式与牌头语言 → 默认自动上屏（清单存在设备里，换手机读回同一份）
4. **相册轮播**（首页 tab ③）：「把当前画面加入轮播」（最多 8 张）→ 设换图间隔与顺序 → 到点设备自己换下一张
5. **设备设置**：主页右上角 ⚙ 进入 —— 热点改名、局域网联网、休眠与自动唤醒、日历自动改日期、残影清理、恢复出厂
6. **更新**：设置页「上传并升级」一个入口 —— 传 `.bin` = 固件升级（顺带更新控制页、重置 6 项显示/休眠参数，保留热点名/密码、局域网配置、轮播画面与轮播/日历设置、自动重启），传 `.html` = 只更新控制页（不重启）
7. **当天使用日历**：设备设置 → 日历自动改日期 →「同步今天日期」→「立即显示今天」先上一张；勾「自动改日期」并填换日时刻（默认 00:01）后，**从下一个换日时刻起**每天自己改日期（当天不会自动盖掉你刚传的画面）

## ⚠️ 硬件与固件约定

- **色码固定**：`0x00=黑 0x01=白 0x02=黄 0x03=红`（实测标定，与部分参考实现相反，改动前必读 `docs/CONTRACT.md`）
- **几何固定**：帧缓冲为逻辑图 180° 旋转存储，`packIdx` 与驱动严格对应
- 固件**不做任何图像处理**——所有像素由页面在浏览器端合成完毕后才发送
- 请勿在固件中添加蓝牙（ESP32-C3 无 PSRAM，蓝牙会挤占 WiFi 缓冲）
