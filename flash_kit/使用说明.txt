墨印 MoInk 一键刷机包
版本：R1.5.0（固件与控制页共用同一个版本号；2026-10-05，api 保持 2）
================================================

本版四件事：
  ① 日历自动改日期 —— 设备每天在你定的时刻（默认 00:01）自己醒来，
                  把竖版日历上屏后回深睡，不启热点、不联网；**四套版面可选**
  ② 待办清单上屏（新）—— 一句话一条、完成打勾，两套版式；**清单存在设备里**，
                  换手机读回同一份；它**取代原「便签」模式**
  ③ 首页改为三个内容 tab（拍立得 / 待办 / 轮播）—— 换屏幕上放什么不必再进设置；
                  设置页只留设备怎么运行（休眠 / 热点 / 日历 / 升级）
  ④ 唤醒节奏可自定义 —— 「开热点等人」「轮播换图」「日历改日期」各自独立
                  填分钟数（0~1440），不再只有 1/12/24 小时几档；
                  并修掉「选了不休眠 → 轮播 / 日历一次都不触发」的死角

文件夹内容（放在同一个目录）：
  MoInk一键刷机.bat        双击运行（没装 Python 会引导自动安装）
  flash_on_pc.py           刷机脚本（bat 自动调用，也可命令行单独运行）
  moink_R1.5.0_merged.bin  固件整包（0x0 写入，含 bootloader + 分区表 + 固件）
  moink_R1.5.0_app.bin     OTA 升级包（设备已能开机时，在网页里上传）
  page-R1.5.0.html         创作页面（网页里「① 升级」上传，免刷机）
  test_frame_post.py       诊断工具（PC 直连发四色测试帧，验证显示链路）

※ 日历与待办都在**固件**里：只把 page-R1.5.0.html 热更到 R1.4.0 设备，
   日历面板会提示「此设备固件不含日历功能（需 R1.5.0 及以上）」，
   待办 tab 会提示「设备固件不含待办功能（需 R1.5.0+ 固件）」，其它功能照常。
※ 便签模式已下线：老浏览器里写过的便签文字，打开新页面时会**自动并进拍立得那份**（不丢字）。

怎么升到本版
------------------------------------------------
【推荐】方式 A：设备现在跑 R1.2.0 或以上，网页里直接升
  1. 控制页「设置 → 系统维护与升级 → ① 升级」，把 moink_R1.5.0_app.bin 选进去
  2. 等设备重启完成（约 1 分钟）
  3. 重启后页面自动变成新版（控制页随固件一并更新），版本显示 R1.5.0

方式 B：需要整包刷写 / 首次使用
  1. 如果这台电脑没有 Python，双击 MoInk一键刷机.bat 会询问「是否自动下载并安装」，
     输入 y 回车即可。
  2. 用【数据线】（能传数据的，不是纯充电线）把板子接到电脑 USB 口。
  3. 双击 MoInk一键刷机.bat，等它自动选串口、自动刷写（约 1~2 分钟）。
     脚本只认带 VID 的真实 USB 串口，蓝牙等虚拟串口（无 VID）会自动跳过。
  4. 看到 [OK] 刷机完成即可。手机 Wi-Fi 连 MoInk-XXXX（默认开放）→
     浏览器打开 http://192.168.4.1

※ 方式 B 会整体覆盖设备上的现有固件与设置。
※ R1.1.x 及更早版本的设备必须走方式 B（线刷）：分区表不同，不能直接 OTA。

★ 网页里升级只需选文件，不用判断类型
------------------------------------------------
R1.2.0 起只有一个升级入口，本版沿用：
  · 传 moink_R1.5.0_app.bin（.bin）→ 固件升级：写备用分区 → 校验 → 切槽
    → 顺带更新控制页 → 重置 6 项显示/休眠参数 → 自动重启
    （保留：热点名/密码、局域网配置、轮播画面、轮播与日历设置）
  · 传 page-R1.5.0.html（.html）→ 只热更控制页：CRC32 校验 → 替换
    → 不重启，刷新浏览器即可
设备按文件**内容**识别（固件首字节 0xE9 / 页面以 <!doctype 或 <html 开头），
不看后缀名，也不看浏览器报的类型。

注意事项
------------------------------------------------
- 不要用浏览器网页烧录器！本板是 C3 原生 USB-JTAG（VID 0x303a），
  网页烧录器（WebSerial）会卡死在 "Stub running..."，一个字节都写不进。
- 如果卡死或失败：拔插一次 USB，然后在本目录打开命令行运行：
      python flash_on_pc.py --no-stub
- 查看本机全部串口：
      python flash_on_pc.py --list
- 升级会重置这 6 项：屏幕档位 / 左右翻转 / A1 写入模式 / WiFi 功率 / 休眠档位 /
  **自动唤醒（回落「关闭」）**。热点、联网、轮播、日历设置都不动。
- 「不休眠」不等于永不入睡：开了任一节奏（开热点等人 / 轮播换图 / 日历改日期）时，
  空闲约 3 分钟后设备照样深睡 —— 否则定时器没被武装，节奏一次也不会触发。
- 日历需要**日期同步**：设备断过电日期就丢了，此时自动改日期会停住（不会上屏错误
  日期）。重新打开一次设备页会自动补回，或在日历卡片点「同步今天日期」。
- 日历与轮播抢同一块屏：同一次唤醒只做一件事（日历优先），两者会互相盖掉对方
  刚上屏的画面 —— 建议二选一。
- 按 GPIO5 按键唤醒只进管理页，**不会**换图、也不会改日历（设计如此）。

刷完验证（两项常规 + 五项验收）
------------------------------------------------
1. 控制页「设置」设备状态应显示：版本 R1.5.0 / 接口 2。
2. 传一张图，屏幕应在约 15~25 秒内完成刷新。

□ V1 固件升级保留要键：上传 moink_R1.5.0_app.bin → 设备重启后版本显示 R1.5.0，
   上述 6 项回到默认，而**热点名/密码、局域网配置、轮播画面与轮播/日历设置保持不变**。

□ V2 页面热更不重启：上传 page-R1.5.0.html → **不重启**，
   刷新浏览器页面即生效，版本显示 R1.5.0。

□ V3 自定义节奏：设置 →「休眠与唤醒」→「自动唤醒」填 **1** 分钟并保存
   → 提示应显示「每 1 分钟」；约 3 分钟后设备自己醒来开热点（此时页面掉线属正常）。
   轮播卡片里的「换图间隔」同样可填任意分钟数，两者互不影响。

□ V4 日历（新）：设置 →「日历自动改日期」→
   ①「设备日期」显示今天的日期（首次打开会自动同步一次）；
   ② 点「立即显示今天」→ 约 15~25 秒后屏上是**竖版日历**；
   ③ 勾「自动改日期」、换日时刻保持 00:01 →「保存日历设置」→
      「下次改日期」显示设备自己的倒计时（形如「约 7 小时 30 分后（每天 00:01）」）。
   ※ 当天不会自动刷：今天被视为已处理，倒计时指向明天 —— 这是「不抢屏」设计。

□ V5 局域网联网（回归项）：设置 →「局域网连接」→ 勾「启用联网」，填家里 WiFi 名/密码
   → 保存后设备信息出现「局域网 IP」；手机连同一 WiFi，用这个 IP 打开创作页能正常传图。

本版主要更新（相对 R1.4.0）
------------------------------------------------
- ★ 日历自动改日期：竖版日历（552x768 逻辑画布旋进横屏帧，全程只有一块 106 KB 缓冲；恒为竖版，无横版开关）；
  两套样式都是视觉情绪板方案的一比一复刻，在设备设置里选：
    · 暖纸（默认，方案 B1）= 圆角黄块（黄/白斜纹混色，无描边框）内三行黑字「2026年10月 / 5 / 星期三」+ 不画格线的周一起月格，
      今日 = 黑色实心圆反白数字，节假日 = 数字下方一个红点；没有月份重复标题、没有落款；
    · 红格（方案 A1）= 超大红色日期 + 红色星期 + 大圆角外框月格（内部分格线走直角），今日 = 圆角红底反白，节假日 = 圆角黄底黑字；
    · 翻页牌（方案 C）= 粗黑大 R 外框 + 下缘芥末色带，左上黑色「翻页牌」瓷砖里放白色大日期（砖中横缝 + 两颗铰链铆钉），
      右上月份 + 红字年与星期，下半部竖列月格，今日 = 红底反白瓷砖，节假日 = 芥末底黑字；
    · 打卡点阵（方案 D）= 黑底圆角头部牌（月份白 + 年芥末）+ 左侧星期、右侧大红日期，主体是每行 5 个日期圆点的打卡墙，
      今日 = 实心红点反白，过去 = 黑点，未来 = 空心圈，节假日 = 芥末点。
    四套凡是带框的地方都是大圆角，没有直角方框。
  支持中文 / English 两种文案；法定节假日按固件内置表自动标记（2026 全年 + 2027 元旦，跨年需补表）。
  每天到「换日时刻」自己醒来上屏再回深睡，不开热点。
  日期由页面推给设备（伪 UTC 口径，固件零时区算法），掉电后由页面静默补回。
  只新增四个持久设置（开关 + 时刻 + 语言 + 样式），升级保留、恢复出厂清除。
- ★ 节奏自定义：自动唤醒（开热点等人）与轮播换图彻底解耦，均改为自由分钟数；
  三个节奏各自倒计时，设备按最近到期者武装 RTC 定时器（最短 30 秒防抖）；
  页面只显示设备给的倒计时，不再自行推算。
- ★ 修死角：R1.4.0 选「不休眠」时定时器从未武装 → 轮播一次也不换图。
- ★ 控制页：新增「待办」tab（输入 + 添加、逐条打勾、上移 / 下移 / 删除、版式 A/B、牌头中英、
  勾选即上屏开关、立即上屏 / 清空、量化预览、条数与字节计数）；首页改三 tab；
  新增「日历自动改日期」卡片（开关 / 换日时刻 / 日历语言 / 日历样式 / 设备日期 / 下次改日期 /
  同步今天日期 / 立即显示今天），全部就地反馈；轮播新增「换图间隔」与倒计时回显。
- 回归门禁：node tools/smoke_page.js 264 项全绿、0 失败（本版新增 120 项）。
- api 保持 2：帧格式、色彩、几何规格（768x552 / 800x600）均无变化；分区表不变，可 OTA。

旧固件 / 旧页面的不兼容说明（重要）
------------------------------------------------
- R1.1.x 的固件里**没有**统一升级入口（/api/upload）。把 page-R1.5.0.html
  热更到一台还是 R1.1.x 固件的设备上再去点升级，页面会提示
  「设备固件过旧，不含统一升级入口」—— 这是预期行为，请先按方式 B 线刷到本版。
- R1.5.0 固件里同样**没有**老的 /api/ota 与 /api/web 路由，R1.1.x 的旧页面
  也无法升级本版设备。请使用本包里的页面。
- 页面与固件最好同批使用。把本页面热更到 R1.4.0 及更旧固件上：
  「日历自动改日期」会提示「此设备固件不含日历功能（需 R1.5.0 及以上）」，
  轮播的「换图间隔」会提示固件不含独立间隔，其它功能不受影响。
- 恢复内置页面按钮仍在（设置页「① 升级」下方），用于把热更的控制页清掉、
  回到固件内置的那一份；「恢复出厂」会连同轮播与日历设置一起清空。
