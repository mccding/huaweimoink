# 墨印 MoInk R1.5.0 刷机与更新说明

> ⚠️ **本文写的是 R1.5.0 那一批**（日历 / 待办 / 三 tab / 自定义节奏）。当前**已打包、实机安装并验过的版本是 R1.5.8**，
> 以 [`flash_kit/使用说明.txt`](../flash_kit/使用说明.txt) 为准 —— 那里有本版判据（J1 断电重上电自动回日历、
> J2 到点自己换日、L1~L6 轮播节奏与占空比、G1~G6 换日那一拍「刷完就睡」，均已在本机实机跑过）与 R1.5.1~R1.5.8 的差异；
> 接口定义见 `docs/CONTRACT.md`，逐版记录见 `docs/CHANGELOG.md`。

> 版本：R1.5.0（固件与控制页共用同一个版本号；api 保持 2）
> 本文档对应 2026-10-05 打包的 R1.5.0 产物；相对上一发布版 **R1.4.0** 的更新见「四、本版主要更新」。

**本版四件事：**

1. **日历自动改日期（新）** —— 设备每天在你自己定的时刻（默认 00:01）自己醒来，把**竖版日历**（中文 / English 可切，**四套样式「暖纸 / 红格 / 翻页牌 / 打卡点阵」可切**，各自按情绪板方案 B1 / A1 / C / D 一比一复刻）上屏，然后回深睡；**不启动热点、不联网**，完全离线；
2. **待办清单上屏（新）** —— 一句话一条、完成打勾，两套版式（A 横线条目表 / B 红色时间轴）；**清单存在设备里**，换手机打开控制页读回的是同一份；它**取代原「便签」模式**；
3. **首页改为三个内容 tab（拍立得 / 待办 / 轮播）** —— 「屏幕上放什么」全部留在首页，⚙ 设置页只管设备怎么运行；
4. **唤醒节奏可自定义** —— 「开热点等人」「轮播换图」「日历改日期」三件事各自独立填分钟数（不再只有 1/12/24 小时那几档），并修掉「选了不休眠 → 轮播 / 日历一次都不触发」的死角。

## 一、升级包说明（项目根目录）

| 包 | 内容 | 用途 |
|----|------|------|
| `moink_R1.5.0_app.bin`（1,146,000 B） | 应用镜像 | **网页 OTA 升级** —— 设备能正常开机时用 |
| `moink_R1.5.0_merged.bin`（1,211,536 B） | 整包（bootloader + 分区表 + 固件） | **USB 线刷** —— 0x0 整片写入，首次 / 旧版本 / 救砖用 |
| `page-R1.5.0.html`（213,210 B） | 控制页（= `page/index.html`） | **只热更控制页** —— 从升级入口上传，不刷固件、不重启 |

> ⚠️ 日历与待办都在**固件**里。只把 `page-R1.5.0.html` 热更到 R1.4.0 设备上，日历面板会提示
> 「此设备固件不含日历功能（需 R1.5.0 及以上）」、待办 tab 会提示「设备固件不含待办功能（需 R1.5.0+ 固件）」，
> 其它功能照常 —— 想用这两项请刷固件（方式 A 或 B）。

## 二、固件刷法

### 方式 A —— 网页 OTA（推荐；设备当前跑 R1.2.0 或以上）

1. 手机 / 电脑连接设备热点 `MoInk-XXXX`（已配好局域网连接的也可直接用它的局域网 IP），浏览器打开创作页（或访问 `http://192.168.4.1`）；
2. 右上角 **⚙** → 设备设置 → **系统维护与升级** → 「**① 上传并升级**」；
3. 选择 `moink_R1.5.0_app.bin` → 上传；
4. 等待约 1 分钟：写入备用分区 → 校验 → 切槽 → 顺带更新控制页 → **重置 6 项显示 / 休眠参数**（屏幕档位 / 左右翻转 / A1 模式 / WiFi 功率 / 休眠档位 / 自动唤醒回落默认）→ 自动重启；
   **热点名与密码、局域网连接、轮播画面与轮播 / 日历设置都保留**（见第五节）；
5. 重启完成后：**⚙ → 设备信息** 核对「版本 R1.5.0 / 接口 2」。

> 前提：设备当前是 **R1.2.0 或更新（同分区表）** 的版本才可 OTA。
> R1.1.x 及更早分区表不同，分区表只能整包线刷改写 —— 请走方式 B。

### 方式 B —— USB 线刷整包（首次刷 / R1.1.x 及更早 / 救砖）

1. 用**数据线**（能传数据，不是纯充电线）把板子接到电脑 USB 口；
2. 命令行刷入（本仓库自带脚本，自动选串口 + 自动选根目录最新的 `moink_*_merged.bin`）：

   ```bash
   python tools/flash_moink.py
   ```

   - 只认带 VID 的真实 USB 串口，蓝牙等虚拟口自动跳过；`--list` 可查看本机全部串口，`--port COM7` 可指定；
   - 若卡在 `Stub running...`：拔插一次 USB，改用 `python tools/flash_moink.py --no-stub`；
3. 刷完（看到 `done`）：手机 Wi-Fi 连 `MoInk-XXXX`（默认开放）→ 浏览器打开 `http://192.168.4.1`。

（Windows 一键包：`flash_kit/` 目录双击 `MoInk一键刷机.bat`，没装 Python 会引导自动安装。
 使用前请确认包内是 `moink_R1.5.0_*` 文件。）

> ⚠️ **不要用浏览器网页烧录器**（WebSerial / esptool.js）：本板是 C3 原生 USB-JTAG（VID 0x303a），
> 网页烧录器会卡死在 "Stub running..."，一个字节都写不进；卡死后拔插一次 USB 即可恢复。

### 方式 C —— 只热更控制页（可选，不刷固件）

从同一「① 上传并升级」入口上传页面文件（发布包中为 `page-R1.5.0.html`，即 `page/index.html`）→ CRC32 校验 → 只替换控制页，**不重启**，刷新浏览器即生效；校验失败自动回退内置页。
适合只想更新界面 / 交互、固件暂不动的场景；但**日历 / 自定义节奏需要 R1.5.0 固件**，只换页面拿不到这两项（见第一节提示）。

## 三、刷完验证（清单）

- [ ] **V1 版本**：设备信息显示「版本 R1.5.0 / 接口 2」。
- [ ] **V2 传图**：传一张图，屏幕约 15~25 秒完成刷新。
- [ ] **V3 自定义节奏（新）**：设备设置 → 休眠与唤醒 →「自动唤醒」填 **1** 分钟并保存 → 提示变为「每 1 分钟」，约 3 分钟后设备自己醒来开热点（此时页面会掉线，属正常）；轮播面板的「换图间隔」同样可填任意分钟数，与自动唤醒互不影响。
- [ ] **V4 日历（新）**：设备设置 → 日历自动改日期 →
      ①「设备日期」应显示今天的日期（首次打开页面会自动同步一次）；
      ② 点「**立即显示今天**」→ 约 15~25 秒后屏上是**竖版日历**；
      ③ 勾「自动改日期」、换日时刻保持 `00:01` →「保存日历设置」→ 「下次改日期」显示设备自己的倒计时（形如「约 7 小时 30 分后（每天 00:01）」）；
      ④ **当天不会自动刷**，这是刻意的「不抢屏」设计：今天已被记成处理过，倒计时指向**明天**的换日时刻；当天想立刻上屏就用 ② 的手动按钮。跨过零点后再打开设备页，可以看到日期已经自己变了；
      ⑤ 「日历语言」选 **English** → 保存 → 提示「✓ 已保存 · 每天 00:01 自动上屏 · 已按新语言 / 样式重排画面（约 15~25 秒）」，屏上换成 `OCTOBER 2026 / 5 / WEDNESDAY`；什么都不改再点一次保存 → 提示「✓ 设置未变化，无需保存」（不发请求）；
      ⑥ 「日历样式」选 **红格** → 保存 → 同样的重排提示，屏上变成**大红日期 + 大圆角格线月格**（今日圆角红底反白、节假日圆角黄底）；关掉「自动改日期」再换样式 → 提示「✓ 已保存（自动改日期当前关闭，语言 / 样式切换不会改动当前画面）」，画面不动；刷新页面后下拉框应回显设备里存的样式。
- [ ] **V5 不休眠不再卡死（新）**：休眠档位选「不休眠」+ 开着任一节奏 → 空闲约 3 分钟后设备**仍会深睡**，节奏照常触发（R1.4.0 的坑：选不休眠后轮播一次也不换图）。
- [ ] **V6 局域网联网**（回归项）：连上路由器后「设备信息」出现局域网 IP，同一 WiFi 下用该 IP 打开创作页传图。

## 四、本版主要更新（相对 R1.4.0）

### ★ 日历自动改日期（功能1）

- **竖版日历直接画在帧上**：逻辑画布 552×768（把设备逆时针转 90° 阅读），月历表从**周一**排到周日；四套样式共用同一批字模、同一条中线、同一份月格算术与同一张节假日表，只是配色、字号档位与「怎么标今日 / 节假日」不同：
  - **暖纸**（默认）：上半屏一块**圆角黄块**（**没有描边框**，用黄/白斜纹在远处混成实一档的黄，比参考图的浅奶油更饱和），块内三行黑字
    「2026年10月」→ 超大号日期 → 「星期三」；下面是**不画格线**的白区月格（**不重复月份标题、没有落款**），
    **今日 = 黑色实心圆里的白数字**，**节假日 = 数字下方一个红点**；
  - **红格**：整页白底，顶行小字「年 / 月」，下面是**超大红色日期 + 红色星期**，再接**大圆角外框 + 直角分格线**的月格，
    **今日 = 圆角红底反白**，**节假日 = 圆角黄底黑字**。
  - **翻页牌**：粗黑大圆角外框压住全页 + 下缘一整条芥末色带；左上是黑色大圆角「翻页牌」瓷砖，里面放白色大日期
    （砖中一道横缝 + 两颗铰链铆钉），右上月份、其下红字年与星期；下半部是圆角描边月格（**竖排 7 列、列内自上而下**），
    **今日 = 红底反白瓷砖**，**节假日 = 芥末底黑字**；
  - **打卡点阵**：黑底圆角头部牌（月份白 + 年芥末），其下左侧星期、右侧**大红色日期**；主体是**每行 5 个日期圆点**的打卡墙，
    **今日 = 实心红点反白**，过去 = 黑点，未来 = 空心圈，节假日 = 芥末点。
  四套版面**凡是带框的地方都是大圆角**（黄块、红格外框与色块、翻页牌瓷砖与月格、打卡牌头），没有直角方框。
- **中英双语可切**：设备设置里选「日历语言」→ 中文（`2026年10月 / 星期三 / 一 二 三 …`）或 English（`OCTOBER 2026 / WEDNESDAY / M T W …`）；
  版式与几何完全相同，只换文案和字模。**日历恒为竖版**，不提供横版开关。
- **每天到「换日时刻」自己醒来**：默认 `00:01`，可填任意 `时:分`；到点唤醒 → 上屏当天日历 → 立刻回深睡，**全程不启动热点、不联网**，不占电量在射频上的时间；
- **日期由页面推给设备**：点「同步今天日期」把手机上的日期交给设备（一次写入即可长期走时）；页面每次打开设备页都会检查，发现设备掉过电（日期不可信）就**静默补一次**；
- **不抢屏**：开启「自动改日期」**当天不会**自动盖掉你刚传上去的画面 —— 第一张日历必须你自己点「立即显示今天」；此后每个换日时刻才自动刷。定时渲染无论成功失败都把「今天」记为已处理，不会出现秒级连醒连刷；
- **绝不显示 1970**：设备日期不可信时（刚断电重上电），日历节奏直接不参与定时，宁可不动也不上一张错误日期；
- **只有四个持久设置**（开关 + 换日时刻 + 语言 + 样式），**升级保留、恢复出厂清除**。

### ★ 待办清单上屏（功能3，取代「便签」）

- **设备是清单的持久层，不是渲染器**：`GET/POST /api/todo` 收发**同一份 JSON 原文**（条目 / 完成标记 / 版式 / 语言 / 是否自动上屏），固件不解析内容，只把三道字节闸门（长度 ≤ 1536 B、首 `{` 尾 `}` 且含 `"items"` 键、体里无 NUL）；
- **真源在设备**：清单存在设备 NVS（键 `todo_doc`），换一台手机打开控制页读回的是同一份、勾到第几项也带过来；**固件升级不丢**，只有恢复出厂 / 长按按键会连同轮播画面一起清空；
- **两套版式在浏览器里画**（任意中文只有页面画得出来，固件里只有离线烘焙的字模表）：**A 横线条目表** = 黑牌「今天」+ 黄字日期、每行一条分隔线、完成 = 实心方块打勾 + 删除线、当前项红方块、底部完成方点 + 红色 `n/N`；**B 红色时间轴** = 黑牌两行（大字日期 + 工作日 / 休息日）+ 红脊 + 当前项黄底 + 序号黑块。都含自动缩字号与截尾，**预览画的就是上屏的那张**（同一套四色量化）；
- **操作模型**：一个输入框 +「添加」追加一条（回车同效）、行首独立勾选、可删除 / 上移 / 下移，上限 **12 条 × 每条 20 字**；「勾选即上屏」默认开（每次改动自动重排上屏，约 10~20 秒闪刷），关掉就只存不上屏、需要时点「立即上屏」；
- **待办不进轮播**：与轮播键、与定时唤醒都没有交集 —— 你改一次它上屏一次，设备不会自己醒来换清单；
- 画面上的日期取**手机上的今天**（渲染在浏览器完成），所以**不需要先同步设备日期**。

### ★ 首页三个内容 tab（拍立得 / 待办 / 轮播）

- 首页顶部三个 tab 并排，**「屏幕上放什么」不再藏在设置里**；原「相册轮播」「待办清单」两张折叠卡整块搬进各自 tab；
- 设置页只留设备怎么运行：设备信息 / 休眠与唤醒 / 热点 / 局域网 / 屏幕设置 / 日历自动改日期 / 系统维护与升级 / 恢复出厂；
- 上次停在哪个 tab 会记住（存在浏览器里）；切回拍立得会重排文字覆盖层，进轮播会重读设备上的画面列表；
- **「便签」模式下线**：拍立得升格为一个 tab，模式切换条随之删除。**拍立得的加字功能逐字未动**（「添加文字」勾选仍是唯一开关，文字对象 / 折行 / 描边 / 拖拽 / 留白自动排字全部保留）；老浏览器里写过的便签文字会**一次性并进拍立得那份**，不丢字。文字面板里旧的「待办列表 / 行首空心方框 / 自动缩字号」三件套一并下线 —— 清单现在有自己的 tab。

### ★ 唤醒节奏可自定义（功能2）

- 「自动唤醒（开热点等人）」与「轮播换图间隔」都改成**自由分钟数 0~1440**（0 = 关闭），不再只有 1 / 12 / 24 小时几档；
- **轮播换图不再借用自动唤醒的间隔**：两者彻底解耦、各自独立计时；到期换图时同样直接上屏、不开热点；
- 三个节奏（开热点 / 换图 / 改日期）由设备取**最近的一个到期时刻**武装定时器（最短 30 秒防抖）；页面只显示设备给的倒计时，不再自己推算 —— 以前那句「还剩多久换图」可能是说谎的；
- 修掉 R1.4.0 死角：**选「不休眠」时定时器从未被武装 → 轮播一次也不会换图**。现在只要开了任一节奏，空闲 3 分钟后照样深睡，把定时链路跑起来（页面提示已改为诚实说明）。

### ★ 控制页改动

- 设备设置新增「**日历自动改日期**」卡片：开关 / 换日时刻 / **日历语言（中文 · English）** / **日历样式（暖纸 · 红格 · 翻页牌 · 打卡点阵）** / 设备日期 / 下次改日期 / 同步今天日期 / 立即显示今天，全部就地反馈（操作中 → ✓ / ✗），不再跑到图片页提示；
  换语言或换样式时：日历开着会明确告诉你「已按新语言 / 样式重排画面（约 15~25 秒）」，关着则告诉你「语言 / 样式切换不会改动当前画面」；设置与设备当前值完全一致时页面自己拦下（不发请求）；
- 轮播卡片新增「换图间隔」分钟数与「下次换图（设备倒计时）」回显；休眠卡片的新节奏提示重写；
- 老固件兼容：不含日历 / 不含独立换图间隔的设备，页面明确提示需要 R1.5.0，不静默失败；
- 回归门禁：`node tools/smoke_page.js` **264 项全绿 / 0 失败**（本版新增 120 项 —— 日历的时分换算、状态回显与语言 / 样式回填，以及待办的归一钳位 / 键顺序 / UTF-8 字节 / 回读核对 / 四种失败文案 / 勾选排序删除的写回内容 / 墨迹量宽与对齐回归，都在 Node 最小沙箱里**真实执行**并逐条校验，另含与 `src/todo.h` / `src/todo.c` 的跨文件一致性断言）；帧契约零回归。
- Flash 占用 **87.4%**（1,145,292 / 1,310,720 B，余量约 162 KB），RAM 13.8%。

### 契约与兼容

- **api 保持 2**：帧格式、色码、几何零变动；**分区表不变**（可直接 OTA）。
- 新增 4 条路由（`/api/time` 读写、`/api/calendar/cfg`、`/api/calendar/show`），`/api/info` 新增 `next_wake_s`（距最近一个节奏到期的秒数）。
- 没开日历、没改节奏时，行为与 R1.4.0 完全一致。

## 五、不兼容与注意事项

- **日历 / 自定义节奏需要 R1.5.0 固件**：只热更页面到 R1.4.0 / R1.2.0 固件上，相应面板会提示版本不够，其余功能不受影响。
- **R1.1.x 及更早不能直接 OTA 到本版**：分区表只能整包线刷改写 → 走方式 B（一步到位含 R1.2.0 以来的全部更新）。
- **固件升级会重置这 6 项**：屏幕档位 / 左右翻转 / A1 模式 / WiFi 功率 / 休眠档位 / **自动唤醒（回落关闭）**。
  **保留**：热点名与密码、局域网连接、轮播画面与轮播设置、日历设置。
  → 升级后请用轮播 / 日历前，先到「休眠与唤醒」重新确认自动唤醒是否还要开。
- **日历默认是关的**：升级后请在「日历自动改日期」里勾上开关并保存。
- **换日时刻是「每天」的绝对时刻**：手动点过「立即显示今天」，或当天完成过一次日期同步后，**今天视为已刷**，自动改日期从**下一个**换日时刻开始生效 —— 这是刻意的「不抢屏」设计。
- **设备掉电 = 日期丢失**：断电重上电后设备日期回到起点，此时**自动改日期会停住**（不会上屏错误日期）。重新打开一次设备页即可自动补回，或手动点「同步今天日期」。
- **走时精度**：深睡期间由芯片内部 RC 振荡器计时，出厂按晶振校准过，日级节奏（每天一次）够用；长期累积的偏差靠页面每次打开时重新推日期来收敛。若你希望日历分秒不差地在 00:01 出现，实际触发时刻可能有少量提前 / 滞后。
- **日历与轮播抢同一块屏**：同一次唤醒只做一件事，**日历优先**；两者同时开启时会互相盖掉对方刚上屏的画面 —— 页面会提示，建议二选一（不会替你自动关闭另一个）。
- **唤醒按钮（GPIO5）行为不变**：只管理唤醒，不改日历、不换图。
- 页面侧的画面参数（风格 / 文字 / 工程草稿）存在手机浏览器里，不受升级影响；「恢复出厂」会把日历与轮播设置连同热点、联网配置一起清空。
- 「恢复内置页面」按钮仍在（设备设置 → 系统维护与升级）；控制页为独立分区，校验失败自动回退内置页；固件为双分区（ota_0 / ota_1），刷失败可回滚。

## 六、下一步计划（规划中，未包含在本版）

- **农历 / 节气标注**：本版已按内置的**法定节假日表**标节假日（暖纸 = 数字下红点，红格 = 圆角黄底），但表是手写的 2026 全年 + 2027 元旦，**跨年要补表**；农历日期、节气、调休上班日仍未做（设备端无农历算法，需把离线表进固件）。
- **日历版式恒为竖版**（用户 2026-10-05 定）：不做横版开关；后续只考虑在竖版内加档位（大字 / 极简）。
- **轮播批量导入**：一次挑多张画面存入设备。
